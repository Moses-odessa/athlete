# Тренируйся как атлет (`athlete_index`)

Flutter-приложение для объективной оценки разносторонней физической подготовки:
Индекс атлета (0–100), радар 8 качеств, тесты с нормировкой по полу и возрасту.
См. [техническое задание](ТЗ_Тренируйся_как_атлет_v2.md).

## Реализовано (MVP)

- **Ядро расчётов** `lib/domain/scoring` — баллы, категории, индекс (ТЗ 4.6–4.9),
  чистый Dart без зависимостей от Flutter/БД, покрытие тестами 100%.
- **Онбординг + PAR-Q** (ТЗ 4.1): пол, ДР, вес/рост, опыт, оборудование, цель,
  7 вопросов PAR-Q с предупреждением, принятие соглашения.
- **Дашборд** (ТЗ 4.2): Индекс + уровень, радар 8 качеств, режим «Прогноз»,
  слабое звено, экспорт PDF.
- **Каталог и ввод результата** (ТЗ 4.3, 4.5): формы по типу теста, расчёт балла
  в реальном времени, превью индекса и радара до сохранения.
- **Инфо-модалки** (ТЗ 4.4): 7 разделов на каждый из 12 тестов, RU+EN.
- **История** (ТЗ 4.10): график индекса по времени, дельта, личные рекорды.
- **Настройки** (ТЗ 4.17): единицы, тема, язык, тип шкалы, уведомления,
  экспорт/удаление данных (GDPR).
- **Экспорт в PDF** (ТЗ 4.15): брендированный A4-отчёт с радаром, share sheet.
- **Научная база** (ТЗ 4.16): обоснование тестов, формулы, нормативы, источники.
- **Персистентность** (ТЗ 8.2): Drift (SQLite) на нативных платформах, RU+EN.

> ⚠️ Числовые нормативы и коэффициенты пол/возраст помечены `TODO(calibration)` —
> предварительные, требуют валидации со спортивным экспертом (ТЗ 6, 16 п.1).

## Архитектура

Feature-first + clean layering (ТЗ разд. 10): `core/`, `data/`, `domain/`,
`features/`. Состояние — Riverpod, роутинг — go_router, БД — Drift, графики —
fl_chart, PDF — pdf/printing.

## Команды

```bash
flutter pub get
dart run build_runner build   # кодоген Drift
flutter gen-l10n              # локализации из ARB
flutter analyze
flutter test --coverage
flutter run                   # выбрать устройство (Chrome/Android/iOS)
```

## Требования

Flutter 3.44+, Dart 3.12+. SDK установлен в `C:\src\flutter`.

## Заметки по платформам

- Персистентность работает на iOS/Android (нативный sqlite). В web-превью данные
  живут только в памяти сессии (для полноценного web нужны wasm-ассеты sqlite).
