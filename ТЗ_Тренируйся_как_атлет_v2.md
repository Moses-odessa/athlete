# Техническое задание

## Мобильное приложение «Тренируйся как атлет»

**Версия:** 2.0
**Дата:** 31.07.2026
**Статус:** Черновик для согласования

---

## 1. Общие сведения

### 1.1. Название

«Тренируйся как атлет» (рабочее).

### 1.2. Цель продукта

Дать пользователю объективную, понятную и мотивирующую оценку общего уровня физической подготовки и вести его к уровню разностороннего атлета-натурала через регулярное тестирование и адресные рекомендации.

Приложение — **не** для узкой специализации (бодибилдинг, пауэрлифтинг, бег). Оно про **универсальность**.

### 1.3. Целевая аудитория

- Любители физической подготовки, 18–45 лет, которые уже тренируются или хотят начать системно.
- Атлеты-любители, желающие видеть слабые звенья и балансировать программу.
- Тренеры — как инструмент для тестирования клиентов.

### 1.4. Платформы

- iOS 15+
- Android 9+ (API 28)
- Технология: **Flutter 3.x+, Dart 3.x+**.
- Языки интерфейса на релизе: русский, английский.

---

## 2. Ключевые концепции

### 2.1. Индекс Атлета

Единая интегральная метрика от 0 до 100. Отображается на главном экране крупно, с анимацией изменения.

### 2.2. Радарная диаграмма 8 качеств

- Сила
- Скорость
- Выносливость
- Взрывная сила
- Координация
- Гибкость
- Баланс
- Мобильность

Чем полнее многоугольник, тем универсальнее атлет.

### 2.3. Уровни (градация)

Каждая категория и общий индекс имеют текстовый уровень:

| Диапазон | Уровень |
|----------|---------|
| 0–19 | Novice |
| 20–39 | Beginner |
| 40–59 | Intermediate |
| 60–79 | Advanced |
| 80–94 | Elite |
| 95–100 | Athlete |

Уровень «Athlete» — цель, достижимая единицами процентов пользователей.

### 2.4. Принципы

- **Прозрачность.** У каждого теста, метрики и балла есть объяснение.
- **Персонализация.** Стандарты нормируются по полу и возрасту.
- **Практичность.** После оценки — конкретные шаги по улучшению.
- **Доверие.** Раздел «Научная база» со ссылками на источники.

---

## 3. Роли пользователей

- **Гость** — до онбординга, ограниченный доступ (только просмотр демо-индекса).
- **Атлет** — основной пользователь, тестирует себя и отслеживает прогресс.
- **Тренер** (пост-MVP) — управляет клиентами, экспортирует отчёты.

## 4. Функциональные требования

### 4.1. Онбординг

Собираемые данные:

1. Пол (мужской / женский / не указывать).
2. Дата рождения.
3. Вес (кг).
4. Рост (см).
5. Опыт тренировок (нет / до года / 1–3 / 3+ лет).
6. Доступное оборудование (штанга, гантели, турник, беговая дорожка, гребной тренажёр, велосипед, открытая площадка).
7. Основная цель (общая форма / соревнования / реабилитация / развлечение).
8. **PAR-Q опросник** (7 стандартных вопросов о здоровье). При положительных ответах — предупреждение о необходимости консультации врача перед максимальными тестами.

Принятие пользовательского соглашения и политики конфиденциальности — обязательно.

### 4.2. Главный экран

- Индекс Атлета крупно по центру.
- Радарная диаграмма 8 качеств с анимацией.
- Уровень (Novice…Athlete) под индексом.
- Карточка «Слабое звено» — самая отстающая категория с CTA «Улучшить».
- Быстрый доступ к «Тесту дня».
- Кнопка «Все тесты».
- Кнопка «История».

### 4.3. Каталог тестов

Древовидная навигация: категория → тест.

Карточка теста содержит:

- Название и краткое описание.
- Иконку категории.
- Кнопку «i» (инфо-модалка).
- Текущий балл пользователя и историю.
- Требуемое оборудование.
- Кнопку «Записать результат».
- Кнопку «Как выполнять» (видео/GIF/иллюстрация в MVP — статичная).

### 4.4. Инфо-модалка теста

Обязательные разделы:

1. **Что измеряет** — какое физическое качество и почему.
2. **Зачем нужен** — какая ценность для универсального атлета.
3. **Как выполнять** — пошаговая инструкция.
4. **Как ввести результат** — формат, единицы, что учитывать.
5. **Типичные ошибки** — 3–5 пунктов.
6. **Противопоказания и безопасность** — когда не выполнять.
7. **Влияние на радар** — на какие категории идёт балл.

### 4.5. Ввод результата теста

- Форма с валидацией по типу теста (время, дистанция, повторения, вес, качественная оценка 1–5).
- Автоматический расчёт балла в реальном времени.
- Отображение изменения индекса и радара **до** сохранения (превью).
- Опция прикрепить видео (пост-MVP — для верификации).
- Дата (по умолчанию — сегодня, редактируемая).
- Заметка (свободный текст).

### 4.6. Расчёт баллов теста

**Если больше — лучше:**

```
Балл = ((Результат − Минимум) / (Эталон − Минимум)) × 100
```

**Если меньше — лучше (время, реакция):**

```
Балл = ((Минимум − Результат) / (Минимум − Эталон)) × 100
```

Результат ограничен [0; 100].

**Опциональная нелинейная шкала** (включается в настройках или по умолчанию после валидации):

```
Балл_нелин = 100 × (1 − exp(−k × Балл_лин / 100)) / (1 − exp(−k))
```

где `k ≈ 2.5`. Даёт более быстрый рост в начале и «зону плато» ближе к 100 — реалистичнее для тренировочного прогресса.

### 4.7. Расчёт категории

Среднее арифметическое баллов выполненных тестов в категории.

Если тесты частично не выполнены:

- Категория показывается как «частично оценённая» с прозрачным сектором на радаре.
- Индекс атлета не рассчитывается, пока не сдано **минимум 2 теста в каждой из 8 категорий**.
- Пользователю виден «Прогноз индекса» с индикатором неполноты.

### 4.8. Расчёт Индекса Атлета

```
Индекс = среднее(Сила, Скорость, Выносливость, Взрывная сила,
                 Координация, Гибкость, Баланс, Мобильность)
```

### 4.9. Нормализация по полу и возрасту

Стандарты (Минимум и Эталон) хранятся не как единые числа, а как таблицы по когортам:

```
Cohort = {gender, age_bracket}
age_brackets = [18–24, 25–29, 30–34, 35–39, 40–44, 45–49, 50+]
```

Балл рассчитывается по стандартам когорты пользователя. Пользователь видит уточнение: «Стандарт для мужчин 25–29 лет».

Женские стандарты — примерно 60–80% от мужских по силовым, ~85% по беговым, паритет по гибкости (уточнить на этапе калибровки).

### 4.10. История и прогресс

- График каждой категории по времени.
- График общего индекса.
- Календарь тестирований.
- Дельта с предыдущим замером (+5.2 к «Силе», ↑ уровень с Beginner до Intermediate).
- Личные рекорды по каждому упражнению.

### 4.11. Слабое звено и рекомендации

- Приложение автоматически определяет 1–2 самые отстающие категории.
- Предлагает 3–5 упражнений/паттернов для их прокачки.
- В MVP — статичный контент, заранее подготовленный.
- Пост-MVP — генерация недельного плана с прогрессией.

### 4.12. Peer comparison

- «Ваш индекс выше, чем у X% пользователей вашей когорты».
- Разбивка по категориям.
- Только когорта того же пола и возрастной группы.
- Включается после сдачи полного цикла тестов.

### 4.13. Тест дня / Тест-баттерея

- Готовые наборы из 3–5 тестов, выполнимые за одну сессию (30–60 мин).
- Пример: «Силовая баттерея» — жим, присед, становая (в один день не делают, но как модуль корректно).
- Отдельный экран с таймером и последовательным вводом результатов.

### 4.14. Достижения (бейджи)

- Уровни в каждой категории (Beginner/Intermediate/Advanced/Elite/Athlete).
- Первое прохождение полного цикла тестов.
- Улучшение индекса на 5, 10, 20 баллов.
- Стрики регулярного тестирования.

### 4.15. Экспорт в PDF

- Индивидуальный отчёт: индекс, радар, все тесты, история.
- Формат A4, брендированный.
- Отправка через share sheet.

### 4.16. Раздел «Научная база»

- Обоснование выбора каждого теста.
- Ссылки на первоисточники (ACSM, NSCA, WHO, конкретные исследования).
- Объяснение формулы расчёта.
- Объяснение выбора нормативов.
- Дисклеймер: «Приложение не заменяет медицинскую консультацию».

### 4.17. Настройки

- Единицы измерения (метрические / имперские).
- Тема (система / светлая / тёмная).
- Язык.
- Тип шкалы (линейная / нелинейная).
- Уведомления и напоминания.
- Экспорт данных / удаление аккаунта (GDPR).
- Резервное копирование в облако (пост-MVP).

## 5. Каталог тестов

Ниже приводится справочный набор. Все нормативы **требуют калибровки** на этапе валидации с приглашёнными экспертами по спортивной науке.

### 5.1. Сила

| Тест | Минимум (0) | Эталон (100) | Оборудование |
|------|-------------|--------------|--------------|
| Жим лёжа | 0.3 × BW | 2.0 × BW | Штанга, скамья |
| Присед со штангой | 0.5 × BW | 2.7 × BW | Штанга, стойки |
| Становая тяга | 0.6 × BW | 3.2 × BW | Штанга |
| Подтягивания (строгие) | 0 | 50 | Турник |
| Отжимания на брусьях (строгие) | 0 | 70 | Брусья |
| Прогулка фермера (30 м, вес BW в каждой руке) | не смог | смог без остановки | Гантели/гири |

BW — bodyweight.

### 5.2. Скорость

| Тест | Минимум (0) | Эталон (100) | Оборудование |
|------|-------------|--------------|--------------|
| 30 м | 7.00 с | 3.90 с | Стадион |
| 60 м | 12.00 с | 6.90 с | Стадион |
| 100 м | 18.00 с | 10.80 с | Стадион |
| Челночный бег 10×10 м | 40 с | 23 с | Площадка |
| Тест реакции (визуальный, среднее из 5) | 400 мс | 180 мс | Смартфон |

**Тест реакции** реализуется в приложении: цвет экрана меняется через случайный интервал, пользователь касается. Замер через нативные каналы Flutter для точности (стандартный Ticker даёт ~16 мс погрешности).

### 5.3. Выносливость

| Тест | Минимум (0) | Эталон (100) | Оборудование |
|------|-------------|--------------|--------------|
| Бег 3 км | 20:00 | 10:00 | Стадион/трек |
| Бег 5 км | 35:00 | 17:30 | Стадион/трек |
| Бег 10 км | 75:00 | 37:30 | Трасса |
| Тест Купера (12 мин) | 1600 м | 3600 м | Стадион |
| Гребля 2000 м | 12:00 | 6:20 | Concept2 |
| Велосипед 20 км | 60:00 | 32:00 | Шоссе/тренажёр |

Пользователь выбирает **не все** тесты. Категория считается по имеющимся, но минимум 2 теста для валидной оценки.

### 5.4. Взрывная сила

| Тест | Минимум (0) | Эталон (100) | Оборудование |
|------|-------------|--------------|--------------|
| Вертикальный прыжок | 20 см | 80 см | Лента / приложение |
| Прыжок в длину с места | 140 см | 280 см | Рулетка |
| Бросок медицинбола (5 кг, из-за головы) | 3 м | 10 м | Медбол |

### 5.5. Гибкость

| Тест | Минимум (0) | Эталон (100) | Способ оценки |
|------|-------------|--------------|---------------|
| Наклон вперёд (сидя) | −20 см | +20 см | От уровня стоп |
| Мобильность плеч (задний замок) | пальцы не касаются | ладони соприкасаются | Качественная 1–5 |
| Мобильность таза (Thomas Test) | сильный дефицит | нейтраль | Качественная 1–5 |
| Глубокий присед (без веса) | не выполняет | полная амплитуда, спина ровная, пятки на полу | Качественная 1–5 |

Качественные оценки 1–5 маппятся на 0–100 через таблицу.

### 5.6. Координация

| Тест | Минимум (0) | Эталон (100) | Оборудование |
|------|-------------|--------------|--------------|
| Illinois Agility Test | 25 с | 15 с | Площадка, конусы |
| Тест на точность движений (в приложении) | низкая | высокая | Смартфон |
| Ловля мяча одной рукой (10 попыток) | 0 | 10 | Мяч, партнёр |
| Прыжки со скакалкой на скорость (30 с) | 40 | 100 | Скакалка |

Тест реакции убран из этой категории — он теперь только в «Скорости», чтобы не задваивать.

### 5.7. Баланс

| Тест | Минимум (0) | Эталон (100) | Оборудование |
|------|-------------|--------------|--------------|
| Single-Leg Stand (закрытые глаза), сек | 5 | 60 | — |
| Y-Balance Test (нормированный) | 60% | 100% | Лента, площадка |
| Star Excursion Balance Test | низкий | высокий | Разметка |
| Balance Beam Walk (10 м) | не прошёл | без ошибок | Бревно/лента |

### 5.8. Мобильность

| Тест | Минимум (0) | Эталон (100) | Способ оценки |
|------|-------------|--------------|---------------|
| FMS Overhead Squat | 1/3 | 3/3 | Качественная |
| Ankle Dorsiflexion Test | <2 см | >12 см | Линейка от стены |
| Shoulder Flexion (стена) | предплечья не касаются | руки полностью прижаты | Качественная |
| Hip Internal Rotation | ограничение | полная амплитуда | Гониометрия/качественная |

## 6. Философия оценки

- **100 баллов** — уровень универсального атлета-натурала, тренирующегося годами. Не мировой рекорд.
- **80 баллов (Elite)** — сильный любитель, продвинутый уровень для конкретного качества.
- **60 баллов (Advanced)** — уверенный уровень для здорового активного человека.
- **40 баллов (Intermediate)** — базовая физическая форма.
- **20 баллов (Beginner)** — начальный уровень тренированного новичка.

Полный индекс 100 не должен быть достижим за 1–2 года. Это целевая метрика на 5–10 лет системной работы.

## 7. Верификация результатов

### 7.1. Режимы (пост-MVP)

- **Trust mode** (по умолчанию) — доверяем пользователю. Индекс «личный».
- **Verified mode** — пользователь прикрепляет видео. Модерация автоматом (ML) + выборочная ручная. Индекс «сертифицированный», отображается значком.
- **Coach-verified** — тренер подтверждает результаты в своём приложении.

В MVP реализуется только Trust mode с возможностью сохранять видео локально «для себя».

## 8. Нефункциональные требования

### 8.1. Производительность

- Холодный старт ≤ 2.5 с на устройствах 2022+ года.
- Кадровая частота UI ≥ 60 fps, критические экраны (радар, тест реакции) — 120 fps на поддерживаемых устройствах.
- Расчёт индекса и обновление радара < 100 мс.

### 8.2. Offline-first

- Все тесты и ввод результатов работают без интернета.
- Данные хранятся локально, синхронизация с облаком опциональна.

### 8.3. Приватность

- Соответствие GDPR и применимому законодательству о защите персональных данных страны публикации.
- Данные о здоровье не передаются третьим лицам.
- Экспорт и полное удаление аккаунта.
- Аналитика — только обезличенная.

### 8.4. Доступность

- Крупный шрифт, высокий контраст (пользователь тренируется в зале).
- Поддержка VoiceOver / TalkBack на основных экранах.
- Тёмная тема по умолчанию для экранов, используемых в зале.

### 8.5. Локализация

- Русский, английский на релизе.
- Единицы измерения: метрические/имперские.
- Инфраструктура для последующих языков (испанский, португальский, немецкий).

## 12. MVP (4–6 недель разработки)

**Скоуп:**

1. Онбординг с PAR-Q.
2. 4 категории, 12 тестов:
   - Сила: жим, присед, становая, подтягивания.
   - Выносливость: 3 км, 5 км, тест Купера.
   - Взрывная сила: вертикальный прыжок, прыжок в длину, бросок медбола.
   - Гибкость: наклон вперёд, глубокий присед.
3. Ввод результатов, расчёт баллов и категорий.
4. Радар и Индекс с частичным режимом (fallback при неполных данных).
5. История результатов, графики.
6. Инфо-модалки для всех 12 тестов.
7. «Слабое звено» + статичные рекомендации.
8. Русский язык, iOS + Android.
9. Тёмная/светлая тема.
10. Экспорт результатов в PDF.
11. Раздел «Научная база» (минимальный).

**Вне MVP:**

- Тест реакции (требует нативных каналов).
- Peer comparison.
- Все категории (баланс, мобильность, координация, скорость).
- Верификация видео.
- Cloud sync.
- Многоязычность сверх русского.

## 14. Аналитика

Обязательные события:

- Регистрация, завершение онбординга, отказ от PAR-Q.
- Открытие теста, начало ввода результата, сохранение, отмена.
- Полный цикл тестирования (все 8 категорий).
- Изменение индекса ≥ 5 баллов.
- Использование инфо-модалок.
- Открытие «Научной базы».
- Экспорт PDF.

Метрики продукта:

- Time-to-first-index (медиана времени от установки до первой оценки).
- Retention D1/D7/D30.
- Доля пользователей с полностью заполненным радаром.
- Частота ретестов.

## 15. Безопасность и юридические требования

- PAR-Q обязателен перед первым тестом с силовыми ≥ 1×BW или максимальным спринтом.
- Дисклеймер на каждом экране ввода результатов максимальных тестов.
- Предупреждение о необходимости разминки и техники безопасности.
- Информация о рисках в тестах с высокими нагрузками (становая, спринт, максимальные прыжки).
- Возрастное ограничение: 16+ (с согласия родителей до 18).
- Хранение данных о здоровье — в соответствии с локальными законами страны публикации.

## 16. Открытые вопросы (требуют решения до старта разработки)

1. **Калибровка нормативов.** Кто и на основе каких данных финализирует таблицы стандартов по когортам? Нужен ли консультант по спортивной науке?
2. **Монетизация.** Free / freemium / one-time / подписка? Что бесплатно, что за деньги?
3. **Brand identity.** Название финальное? Логотип, палитра, тон коммуникации.
4. **Тон рекомендаций.** Тренерский, дружеский, нейтральный?
5. **Юрисдикция публикации.** Мировой релиз или поэтапный запуск по регионам?
6. **Партнёрства.** Интеграции с залами, тренерами, спортивными брендами — на каком этапе?
7. **Пользовательский контент.** Разрешаем ли комментарии к результатам, соцпрофили?
8. **Модерация.** Как будут проверяться сомнительные результаты в Peer comparison, чтобы не портить статистику когорт?

## 17. Критерии приёмки MVP

- Пользователь может пройти онбординг за ≤ 3 минуты.
- Пользователь может ввести результат теста и увидеть его на радаре за ≤ 30 секунд.
- Все 12 тестов MVP имеют инфо-модалки на русском.
- Радар и индекс корректно рассчитываются при полных и частичных данных.
- История результатов корректно отображается с графиками.
- Экспорт PDF работает и корректно рендерит радар.
- Приложение проходит ревью Apple App Store и Google Play.
- Crash-free sessions ≥ 99.5%.
- Покрытие юнит-тестами модуля scoring ≥ 90%.
